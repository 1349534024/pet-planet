# 给队友的使用说明

大家统一基于这个项目开发，不要各自重新建后端工程。

## 你们拿到项目后先做这几步

1. 进入后端目录：

```bash
cd backend
```

2. 创建虚拟环境并安装依赖：

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

3. 复制环境变量：

```bash
copy .env.example .env
```

4. 修改 `.env` 里的数据库连接。

5. 执行数据库迁移：

```bash
alembic upgrade head
```

6. 启动项目：

```bash
uvicorn app.main:app --reload
```

7. 打开接口文档：

```text
http://127.0.0.1:8000/docs
```

## 分支约定

推荐大家从 `develop` 拉分支：

```text
feature/a-base-user-pet
feature/b-mall-order-payment
feature/c-merchant-adoption
feature/d-admin-audit
```

每天开发前先拉最新 `develop`，避免冲突堆到最后。

## 开发规则

每个人只在自己的模块里写业务代码。

新增一个模块时，统一建这 5 类文件：

```text
api/v1/模块名.py
models/模块名.py
schemas/模块名.py
services/模块名_service.py
repositories/模块名_repo.py
```

接口必须统一返回：

```json
{
  "code": "SUCCESS",
  "message": "success",
  "data": {}
}
```

不要自己发明新的返回格式。

## 数据库规则

任何表结构变化都必须通过 Alembic。

禁止：

- 手动改数据库后不提交迁移。
- 直接修改别人已经合并的迁移文件。
- 金额使用 float。
- 日志记录敏感明文。
